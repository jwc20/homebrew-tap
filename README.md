# jwc20/homebrew-tap

```bash
brew install jwc20/tap/pokerland-tracker
pokerland-tracker login
brew services start pokerland-tracker
```

`pokerland-tracker` uploads PokerStars hand histories to Pokerland. Source:
[jwc20/pokerland-trackers](https://github.com/jwc20/pokerland-trackers). The
formula is updated by that repo's release workflow.
